# Catalog and tagging

The [machine-readable index](index.json) enables discovery without guessing file paths. Each entry links to its complete asset manifest.

| ID | Type | Tags | Status |
| --- | --- | --- | --- |
| [armorheart-battleship](../assets/vehicles/armorheart-battleship/README.md) | vehicle | `boss`, `top-down`, `stylized`, `mixed-raster-vector`, `png` | **accepted-for-origin**; rights **unverified** |

Filter with `type`, `tags.roles`, `tags.styles`, `tags.views`, `tags.features`, or `tags.formats`. Tags state **what it is**, not permission to use it. Avoid one-off tags when a stable synonym already exists.

Catalog entries can be `candidate`, `accepted-for-origin` or `asset-frozen`. **Accepted-for-origin is not automatically frozen for arbitrary reuse.** A future character enters the catalog only once its actual reusable animation/source package exists; concept-only images may be linked as work in progress, not misrepresented.
